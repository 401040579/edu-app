# EduApp - 用户体验设计文档

> 设计师视角 | v1.0

## 一、设计原则

### 1.1 核心设计理念

**"让思考变得可见，让学习像探险。"**

EduApp不是一个冰冷的学习工具，而是一个温暖的思考空间。设计的核心目标是：

1. **降低思考的门槛** — 让学生觉得"想一想"不难、不丢人
2. **让思考过程可见** — 通过可视化让抽象的思维过程变得具象
3. **制造发现的喜悦** — 每次"想通了"的时刻都是一次小小的胜利
4. **保持专注而不焦虑** — 不用分数和排名制造压力，而用好奇心驱动学习

### 1.2 设计原则

| 原则 | 说明 | 具体要求 |
|------|------|---------|
| 🧘 沉浸专注 | 学习需要深度专注 | 无干扰界面，隐藏非必要元素 |
| 🌱 成长可见 | 进步应该看得见 | 知识图谱可视化成长 |
| 🤝 伙伴感 | AI是同伴不是工具 | 温暖的语气、个性化交互 |
| ✨ 发现惊喜 | 学习充满惊喜感 | 概念发现时的动效庆祝 |
| 📱 极简操作 | 14岁学生也能轻松使用 | 最多2步到达核心功能 |

## 二、视觉风格

### 2.1 色彩系统

```
主色调：深夜蓝 (#1A1F36) — 沉浸、专注、像星空一样激发探索
辅助色：
  - 智慧紫 (#7C5CFC) — 代表思考和发现
  - 生长绿 (#34D399) — 代表成长和进步
  - 温暖橙 (#F59E0B) — 代表成就和鼓励
  - 专注白 (#F8FAFC) — 文字和内容区域

背景：深色模式为默认（减少视觉疲劳，适合长时间学习）
      支持浅色模式切换
```

### 2.2 字体

```
中文标题：思源黑体 Bold
中文正文：思源黑体 Regular
英文/数字：Inter
代码/公式：JetBrains Mono
```

### 2.3 设计风格

- **风格**：现代极简 + 微动效
- **卡片**：圆角(12px)、柔和阴影
- **图标**：线条风格（Lucide Icons）
- **插画**：抽象几何风格，避免低龄卡通
- **动效**：功能性动效（概念发现时的粒子效果、知识图谱生长动画）

### 3.3 关键交互细节

#### 对话界面

**阶段指示器**：
- 顶部显示当前对话阶段（探索 → 引导发现 → 巩固 → 反思）
- 使用进度条+文字，让学生知道"我们走到哪了"
- 每进入新阶段有微妙的颜色渐变

**提示按钮（核心交互）**：
- 初始显示为 "给我一点提示 💡"
- 点击后AI给出模糊提示（方向性引导）
- 再次点击显示 "再给一点 💡💡"（更具体的提示）
- 第三次显示 "最后提示 💡💡💡"（接近答案但仍需学生最后一步推理）
- 整个过程不直接给答案

**概念发现动效**：
- 当学生成功推导出一个关键概念时
- 屏幕出现柔和的星光粒子效果
- AI回复带有特殊的庆祝标识
- 右侧知识图谱新增节点并发光

**情绪检测反馈**：
- 如果学生连续3轮回答偏短或使用消极词汇
- AI自动切换为更鼓励的语气
- 界面微妙地从"挑战模式"切换到"支持模式"（色调变暖）

## 四、游戏化元素设计

### 4.1 设计原则
教育游戏化不是"贴勋章"，而是让学习过程本身具有内在驱动力。

**避免的做法：**
- 不使用排行榜（避免竞争焦虑）
- 不使用惩罚机制（连续中断不扣分）
- 不将勋章与"做题数量"挂钩

**采用的做法：**
- 奖励思考深度而非速度
- 庆祝发现而非正确率
- 展示成长而非排名

### 4.2 成就系统

#### 思维品质类

| 成就 | 条件 | 设计 |
|------|------|------|
| 深度思考者 | 一次对话中独立推导出3+个概念 | 紫色思想家图标 |
| 联想大师 | 主动建立2个不同学科概念的联系 | 彩虹桥图标 |
| 自我纠正者 | 主动发现并纠正自己的5次错误推理 | 镜子图标 |
| 提问者 | 向AI提出10个高质量问题 | 问号皇冠图标 |

#### 探索精神类

| 成就 | 条件 | 设计 |
|------|------|------|
| 好奇探索家 | 探索5个不同学科 | 指南针图标 |
| 知识拓荒者 | 知识图谱达到100个概念节点 | 星球图标 |
| 连续思考家 | 连续7天进行学习对话 | 火焰图标 |
| 午夜哲学家 | 在晚上10点后完成一次深度对话 | 月亮图标 |

#### 里程碑类

| 成就 | 条件 | 设计 |
|------|------|------|
| 第一次发现 | 完成第一次概念发现 | 种子发芽图标 |
| 知识网络 | 知识图谱首次出现跨学科连接 | 网络图标 |
| 思维蜕变 | 布鲁姆认知层次首次达到"评估"或"创造" | 蝴蝶图标 |

### 4.3 学习动力机制

#### 好奇心引擎

**未探索概念（"迷雾区"）**：
- 知识图谱中，已探索区域周围显示模糊的"迷雾"节点
- 鼠标悬停显示："这里有一个有趣的概念等待你发现..."
- 点击进入新的苏格拉底对话
- 利用人类天然的好奇心和探索欲

**每日思维挑战**：
- 每天一个跨学科问题（如"为什么音乐能影响情绪？"涉及物理+生物+心理学）
- 不计时、不打分，纯粹激发思考
- 完成后展示其他学生的不同思考路径（匿名）

#### 社交动力

**思维地图分享**：
- 一键生成精美的思维发现海报
- 分享到微信/朋友圈："今天我自己推导出了XXX！"
- 强调"发现过程"而非"正确答案"

**学习小组（v0.3）**：
- 2-3人+AI一起探索同一个问题
- AI协调讨论，确保每个人都参与
- 小组思维地图合并，展示不同思路

## 五、注意力保持策略

### 5.1 对话节奏设计

```
对话长度：推荐15-25分钟（8-15轮有效交互）
节奏控制：
  → 前3轮：轻松探测，建立舒适感
  → 4-8轮：核心引导，逐步深入（高认知负荷）
  → 9-12轮：发现与巩固（认知高潮）
  → 13-15轮：反思与总结（认知放松）

避免：
  → 单次对话超过30分钟（建议休息提醒）
  → AI回复过长（每次不超过3段）
  → 连续高难度问题（穿插鼓励和总结）
```

### 5.2 认知负荷管理

| 策略 | 实现方式 |
|------|---------|
| 分块呈现 | AI每次只引导一个概念点 |
| 视觉锚点 | 对话旁实时生长的思维节点分散认知压力 |
| 进度感知 | 阶段指示器让学生知道"快到了" |
| 适时总结 | 每发现一个概念后，AI简短总结进展 |
| 情绪调节 | 检测到疲劳时切换为轻松话题或建议休息 |

### 5.3 防沉迷设计

- 每日学习时长上限提醒（非强制，默认90分钟）
- 连续学习45分钟后弹出休息建议
- 夜间模式：22:00后自动降低屏幕亮度并建议结束
- 家长端可设置每日使用时间

## 六、响应式设计

### 6.1 设备适配

| 设备 | 布局 | 特殊考虑 |
|------|------|---------|
| 桌面 (>1024px) | 对话左侧+思维地图右侧并排 | 完整体验 |
| 平板 (768-1024px) | 全屏对话，思维地图可切换 | 触控优化 |
| 手机 (<768px) | 全屏对话，思维地图在对话结束后展示 | 键盘适配 |

### 6.2 移动端特殊优化

- 对话输入框自动跟随键盘
- 长按AI消息可以标记"重要概念"
- 左滑对话气泡查看相关概念节点
- 下拉刷新查看每日挑战

## 七、无障碍设计

- 色彩对比度符合WCAG 2.1 AA标准
- 支持屏幕阅读器（对话内容结构化标记）
- 键盘完全可操作
- 字体大小可调（最小14px，最大24px）
- 动效可关闭（尊重prefers-reduced-motion）
