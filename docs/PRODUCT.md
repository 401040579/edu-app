# EduApp - 产品设计文档

> 产品经理视角 | v2.0 | 方向已确定

## 一、产品定义

### 一句话定义
**EduApp是一款AI苏格拉底式学习伙伴**——它不给答案，而是通过引导式提问帮助学生自己发现答案、构建思维能力。

### 产品理念
> "在AI时代，最珍贵的能力不是获取答案，而是提出好问题。"

传统教育产品（包括大多数AI教育产品）的核心逻辑是**"给答案"**——更快、更准、更方便地帮你解题。EduApp反其道而行：我们的核心逻辑是**"引出答案"**——通过苏格拉底式对话，引导学生自己思考、发现、构建知识。

### 产品名称候选
- **SocraticAI** / **苏问** / **思伴** / **问道** / **ThinkMate**
- 最终名称待用户测试确定

## 二、目标用户

### 主要用户画像

#### 画像1：自驱型中学生（14-18岁）—— "小明"
- **背景**：高一学生，成绩中上，对学习有好奇心但不满于应试教育
- **痛点**：
  - 遇到不懂的问题，搜答案/问ChatGPT太容易，感觉自己没真正学会
  - 想深入理解而非死记硬背，但缺乏引导
  - 学习孤独，缺少可以深度讨论的同伴
- **动机**：想成为"真正理解"而非"背答案"的学生
- **使用场景**：课后复习、预习新概念、准备考试时深度理解知识点

#### 画像2：焦虑型家长 —— "王妈妈"
- **背景**：互联网从业者，孩子初二，担心AI时代孩子的竞争力
- **痛点**：
  - 发现孩子用ChatGPT直接抄作业，担心丧失思考能力
  - 想找到培养孩子独立思考的工具
  - 不确定如何在AI时代正确引导孩子学习
- **动机**：希望孩子在AI时代仍然具备不可替代的思考力
- **决策因素**：学习效果可量化、价格合理、使用安全

#### 画像3：创新型教师 —— "李老师"
- **背景**：高中物理老师，教龄8年，关注教育技术
- **痛点**：
  - 班级40+人无法实施一对一苏格拉底教学
  - 想了解每个学生的思维过程而非只看考试分数
  - AI工具大多替代学生思考，与教育理念冲突
- **动机**：找到辅助教学的AI工具，增强而非替代教学
- **使用场景**：课堂互动补充、作业布置、学情分析

### 用户优先级
1. **P0**：自驱型中学生（直接用户，口碑传播）
2. **P1**：焦虑型家长（付费决策者）
3. **P2**：创新型教师（渠道推广者，To B切入点）

## 三、用户旅程

### 核心学习旅程（以"小明学物理"为例）

```
阶段1：发现 → 小明搜索"物理学习AI"，看到EduApp的slogan"不给答案，给你思考的超能力"

阶段2：初体验 → 免费试用，选择"高中物理-力学"
  → 输入问题："为什么月亮不会掉下来？"
  → AI不直接解释，而是反问："你觉得月亮在做什么运动？"
  → 小明："绕地球转？"
  → AI："对！那转弯需要什么条件？想想你骑自行车转弯时..."
  → 小明逐步自己推导出向心力和万有引力的关系
  → 对话结束，生成"思维发现地图"——可视化他的思考路径

阶段3：Aha时刻 → 小明意识到自己"真的理解了"，而不是背了一个公式
  → 查看思维地图，看到自己的推理链条，成就感极强

阶段4：习惯养成 → 每天遇到不懂的概念就来EduApp探索
  → 知识图谱逐渐生长，串联起各个概念
  → AI伙伴记住他的学习风格和知识基础

阶段5：分享传播 → 小明把自己的思维地图分享到朋友圈/班级群
  → "看，我自己推导出了万有引力定律！"
  → 同学被吸引开始使用
```

### 家长旅程

```
发现 → 看到朋友圈分享/教育公众号推荐
了解 → 被"培养思考力而非给答案"打动
试用 → 观察孩子使用，查看学习报告
付费 → 看到孩子思维能力的变化，订阅Pro
推荐 → 在家长群推荐
```

## 五、用户故事（User Stories）

### Epic 1：苏格拉底对话

```
US-001: 作为学生，我希望能选择一个学科和话题开始学习，以便探索我感兴趣的知识。
  验收标准：
  - 可以从学科列表中选择（数学、物理、化学、生物、历史、地理等）
  - 可以输入自定义问题或选择推荐话题
  - 选择后立即进入对话界面

US-002: 作为学生，我希望AI用提问而非直接回答的方式引导我思考，以便我真正理解知识。
  验收标准：
  - AI的回复中至少包含一个引导性问题
  - AI不会直接给出最终答案
  - AI会根据我的回答调整提问方向
  - 当我明显卡住时，AI提供适度提示而非答案

US-003: 作为学生，当我完全卡住时，我希望能获得适度的提示，而不是直接放弃。
  验收标准：
  - 可以点击"给我一点提示"按钮
  - 提示是渐进式的，从模糊到具体
  - 最多3级提示后才给出部分解释
  - 记录提示使用频率用于难度调整

US-004: 作为学生，我希望在对话结束后看到我的思考路径地图，以便回顾我是如何一步步想通的。
  验收标准：
  - 对话结束后自动生成思维地图
  - 地图展示关键概念节点和推理链条
  - 可以点击节点回顾对应的对话片段
  - 可以保存和分享思维地图
```

### Epic 2：学习追踪

```
US-005: 作为学生，我希望看到我探索过的所有知识形成的网络图，以便了解自己的知识版图。
  验收标准：
  - 知识图谱随学习自动生长
  - 不同学科用不同颜色区分
  - 可以点击节点查看相关对话
  - 显示知识点之间的关联

US-006: 作为家长，我希望收到孩子的学习报告，以便了解孩子的思维成长而不仅是刷题量。
  验收标准：
  - 周报包含：探索主题数、思维深度评分、知识覆盖面
  - 重点展示"独立发现"的概念数量
  - 对比上周的思维成长趋势
  - 不包含具体对话内容（保护隐私）
```

### Epic 3：动力机制

```
US-007: 作为学生，我希望有成就奖励来激励持续学习，以便保持学习动力。
  验收标准：
  - "深度思考者"勋章：一次对话中独立推导出3+个概念
  - "好奇探索家"勋章：探索5个不同学科
  - "连续思考"奖励：连续7天学习
  - 成就可分享到社交平台

US-008: 作为学生，我希望每天有一个有趣的思维挑战，以便激发好奇心。
  验收标准：
  - 每日推送一个跨学科思维挑战
  - 挑战有趣且与日常生活相关
  - 完成挑战获得特殊奖励
  - 可以看到其他学生的不同思考路径（匿名）
```

- 每天3次苏格拉底对话
- 基础学科（数学、物理、化学）
- 基础思维地图

### 探索者（Explorer）—— ¥29/月 或 ¥258/年
- 无限对话
- 所有学科
- 完整知识图谱

## 七、核心指标体系

### 北极星指标
**周活跃学习对话数（Weekly Active Learning Conversations）**
- 定义：每周完成至少一次深度对话（>5轮有效交互）的用户数
- 目标：6个月内达到10,000 WAC

### 一级指标
| 指标 | 定义 | 目标 |
|------|------|------|
| 首次对话完成率 | 新用户完成第一次完整对话的比例 | >60% |
| 7日留存率 | 注册后7天内再次使用的用户比例 | >25% |
| 对话深度 | 平均每次对话的有效交互轮数 | >8轮 |
| 独立发现率 | 用户在对话中独立推导出目标概念的比例 | >50% |
| 付费转化率 | 免费用户转为付费用户的比例 | >5% |

### 二级指标
| 指标 | 定义 |
|------|------|
| 提示使用率 | 用户请求提示的频率（越低越好） |
| 知识图谱节点增长 | 用户知识网络的扩展速度 |
| 分享率 | 用户主动分享思维地图的比例 |
| NPS | 净推荐值 |
