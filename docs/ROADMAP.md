# EduApp - 开发路线图

> 方向已确定：AI苏格拉底式学习伙伴 | 更新于 2026年3月

---

## Phase 0：MVP体验原型 — 第1-4周

### 目标
让用户体验"苏格拉底式AI对话"的核心魔力，验证产品假设。

### 交付物
- **Landing Page**：传达"不给答案，给思考力"的产品理念
- **苏格拉底对话引擎**：支持数学、物理基础学科的引导式对话
- **思维发现地图**：对话结束后生成思考路径可视化
- **主题选择器**：选择学科和话题开始探索
- **PWA支持**：移动端可用

### 技术里程碑
- 第1周：项目搭建（Vite + React + TS + Supabase + Claude API）
- 第2周：苏格拉底对话引擎（Prompt系统 + 状态机 + 流式响应）
- 第3周：思维地图可视化（React Flow / D3.js） + 知识图谱基础
- 第4周：Landing Page + PWA配置 + Vercel部署 + 内测邀请

### 成功指标
- 100名种子用户
- 首次对话完成率 > 60%
- NPS > 40

---

## Phase 1：产品打磨 — 第5-12周

### 目标
基于种子用户反馈优化体验，建立付费模型。

### 交付物
- **自适应难度系统**：根据学生表现动态调整提问深度
- **AI伙伴人格选择**：严谨型 / 活泼型 / 挑战型
- **知识图谱**：学过的概念形成可视化网络
- **学习仪表盘**：基础学习数据展示
- **渐进提示系统**：3级提示，从模糊到具体
- **成就系统**：思维品质和探索精神类成就

### 成功指标
- 1000名注册用户
- 7日留存率 > 25%
- 首批付费用户

---

## Phase 2：增长与变现 — 第13-24周

### 目标
验证商业模式，开始规模化获客。

### 交付物
- **付费订阅系统**：免费层 / 探索者(¥29/月) / 家庭版(¥49/月)
- **家长学习报告**：周/月学习数据报告
- **社交分享**：思维地图一键分享到微信/朋友圈
- **更多学科**：化学、生物、历史、地理
- **每日思维挑战**：每天一个跨学科思维挑战
- **内容营销启动**：抖音/视频号/公众号/知乎内容矩阵

### 成功指标
- 200+ 付费用户
- MRR ¥6,000+
- 月新增注册 > 500

---

## Phase 3：B端拓展 — 第25-48周

### 目标
进入学校市场，建立B2B2C模式。

### 交付物
- **教师管理后台**：班级管理、作业布置、学情分析
- **学校版定价方案**
- **多人协作探索**：2-3人+AI一起探索
- **API/SDK**：供教育机构集成
- **跨学科项目**：AI引导的综合性探索项目
- **英文版**（拓展海外市场）

### 成功指标
- 5-10所学校合作试点
- MRR ¥30,000+
- 月新增注册 > 3,000

---

## 总时间线

```
Month 1      │ Phase 0: MVP体验原型 + 种子用户
Month 2-3    │ Phase 1: 产品打磨 + 用户反馈迭代
Month 4-6    │ Phase 2: 增长与变现 + 内容营销
Month 7-12   │ Phase 3: B端拓展 + 学校试点
Month 13-24  │ 规模增长 + 模式验证
```

---

## 关键风险点检查

每个Phase启动前，对照 docs/RISKS.md 检查以下关键风险：
- Phase 0：风险1（用户是否接受"不给答案"？）→ 种子用户验证
- Phase 1：风险3（AI对话质量是否稳定？）→ 质量审计
- Phase 2：风险6（付费意愿是否足够？）→ 定价测试
- Phase 3：风险5（学校获客是否可行？）→ 试点验证
