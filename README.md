> 方向待定，以下为探索方向。

## 可能的方向

### 方向A：AI苏格拉底 - 提问式学习
不直接给答案，通过AI引导式提问让学生自己思考出答案。像苏格拉底一样，用问题教学。

### 方向B：知识图谱学习
把所有知识连成网，学一个点自动关联相关知识，形成完整的知识体系而不是碎片化学习。

### 方向C：实战项目驱动
不上课不看视频，直接做项目。AI实时指导，遇到不会的就地学习，学完继续做。

### 方向D：AI学习伙伴
不是老师，是同学。和你一起学习、讨论、辩论、互相考试的AI伙伴。

### 方向E：技能交换平台
AI匹配互补技能的人，你教我编程，我教你画画。AI辅助教学质量。
